# AnelfAgent 0.4.0

独立桌面安装与管理程序：按步骤完成项目获取、运行环境准备和前端构建，安装完成后直接管理服务。

- 支持 GitHub / Gitee 项目来源，以及国内、国际环境下载源；优先复用已有 uv 和兼容工具。
- Python 依赖由 uv 管理，显示安装阶段、包下载进度和日志；取消后可切换镜像继续安装。
- 支持启动、停止、更新重启、Web 控制台入口、局域网访问、端口和可选访问密码配置。
- 服务停止时可直接更新项目，完成后保持停止；运行时更新并重启。更新过程显示命令日志，中英文取消提示准确区分安装与更新。
- APP、Web 与命令行共用服务控制状态；关闭窗口收起到托盘，退出时可选择安全停止服务。
- 紧凑深色界面、中英文切换、按需展开详情；自动检测空间和端口占用。
- 首次引导支持接入已有 Git 项目：默认迁移，也可保留原目录直接管理。运行中须确认安全停服；同盘快速移动，跨盘显示进度并校验后完成迁移。保留 Git 更改、配置、数据及旧环境备份。
- 接入时识别实际 Git origin，默认沿用原仓库；可明确切换 GitHub / Gitee 官方镜像，保留分支和本地文件，自定义 fork 不会被替换为官方仓库。
- 修复迁移时误拦截项目内相对子模块的问题；外部 Git 关联会指出具体路径。失败摘要直接显示原因，不再将目录结构问题误报为下载源问题。
- 修复 Windows 跨盘迁移 pnpm 目录联接时的盘符报错：统一扩展路径格式，保留目录联接类型、失效目标及串联关系，内部目标重定位、外部目标保持不变；提前检查链接，并支持目录切换后中断恢复。
- 迁移前检查 Windows 目录占用，APP 不再继承启动目录；跨盘迁移支持持久续传，取消或目录切换失败后保留已完成进度，重试仅重新处理变化的文件。
- Windows 卸载默认保留项目、运行环境与配置，可勾选清理 APP 自建数据；已有项目始终受保护。同目录重装可继续接管，覆盖升级保留数据，并兼容旧安装器的项目保护。
- 修复 Web 已启动但桌面仍显示「正在启动」：结合进程归属、监听端口及健康检查判断可用性；运行记录按 PID 保存并定期刷新，过期记录不再掩盖正在运行的 Web。控制通道不可用时仍可打开 Web 控制台，避免误启第二个实例。

## 运行与升级

关停使用独立进度页，准确区分安装取消与服务停止；等待中可返回或仅退出应用。
旧管理器在空闲时安全替换，运行中的项目保持不变；缺少有效控制记录时明确说明原因，不锁住退出界面。
错误详情在状态轮询、提示文本更新时保留展开状态，避免展开后立即折叠。
修复 Windows 覆盖安装误报“无法安全停止”：数据保护脚本运行后彻底移除 Electron Node 模式环境变量，
保证旧版维护入口以桌面模式执行。原生安装器回归检查配置、数据、环境和接管记录保留，以及程序文件替换。
修复从项目目录内运行安装包时被误判为“APP 未关闭”：检测实际客户端，覆盖安装使用新包中的卸载组件，
不按目录范围强杀安装器或项目进程。安装、迁移和关停错误摘要跟随中英文选择，技术详情保留原文。
维护后等待辅助进程释放文件，文件占用支持短暂重试；清理失败显示升级错误与日志路径，不再重复误报“无法关闭”。
中断后的程序替换支持继续执行，项目数据和运行环境保持保留。
已配置项目重新打开时先显示连接状态，成功后直接进入管理页面；安装与迁移表单不会在启动期间闪现，连接失败可在原页重试。

## 安装包

| 系统 | 文件 |
| --- | --- |
| Windows x64 | `AnelfAgent-0.4.0-win-x64.exe` |
| macOS Intel | `AnelfAgent-0.4.0-mac-x64.dmg` |
| macOS Apple Silicon | `AnelfAgent-0.4.0-mac-arm64.dmg` |
| Linux x64（AppImage） | `AnelfAgent-0.4.0-linux-x86_64.AppImage` |
| Ubuntu / Debian x64 | `AnelfAgent-0.4.0-linux-amd64.deb` |

安装包附 SHA-256 校验清单。构建产物仅作为 Release 附件，不提交源码仓库。
包体尚未配置 Windows 代码签名及 Apple 公证，系统可能提示来源未经验证。
各平台经过原生 CI 构建与自动化回归；Windows 安装、覆盖更新与启动接管已有人工验证，卸载选项及 macOS / Linux 的设备实测仍有待覆盖。
首次安装需要联网获取项目及依赖；无桌面环境的 Linux 可继续使用 `start.sh`。
